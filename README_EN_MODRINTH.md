# Hoarding

English | 简体中文

## Design Philosophy

This mod's storage block design is inspired by the storage systems from the following mods:

- [Farmer's Delight](https://modrinth.com/mod/farmers-delight)
- [Quark](https://modrinth.com/mod/quark)

## Features

- **102 Vanilla Storage Blocks**: Various crops, flowers, mushrooms, and loot
- **18 Mod Integration Blocks**: 16 Petals from Botania + 2 from Ars Nouveau
- **9 Items = 1 Storage Block**: Place as building blocks, break to retrieve original items

## Installation

1. Download the latest version ([Releases](https://github.com/3453890470/Hoarding/releases))
2. Install Minecraft Forge 1.20.1
3. Place the .jar file into the `mods` folder in your Minecraft directory
4. Launch Minecraft with the Forge 1.20.1 profile

## Mod Integrations

Required mods must be installed first:

- **Botania** - 16-colored Petals storage blocks
- **Ars Nouveau** - Mage Bloom and Source Berries storage blocks

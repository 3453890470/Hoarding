# Hoarding (NeoForge 1.21.1)

> 从 Forge 1.20.1 移植到 NeoForge 1.21.1 的版本

## 灵感来源

本模组参考了以下模组的存储方块系统设计：

- [Farmer's Delight](https://www.curseforge.com/minecraft/mc-mods/farmers-delight)
- [Quark](https://www.curseforge.com/minecraft/mc-mods/quark)

## 特性

- 支持绝大部分作物、植物和战利品
- 9 个物品合成 1 个存储方块
- 兼具实用性和装饰性
- 兼容 NeoForge 1.21.1

## 支持资源

**原版资源**：各类农作物、花朵、蘑菇、战利品（102+ 种方块）

**模组资源**：

- [Botania](https://www.curseforge.com/minecraft/mc-mods/botania) - 16色矮花箱子
- [Ars Nouveau](https://www.curseforge.com/minecraft/mc-mods/ars-nouveau) - 法师之花箱子、魔源浆果箱子

## 安装

1. 从 [Releases](https://github.com/3453890470/Hoarding/releases) 下载最新版本
2. 安装 Minecraft NeoForge 1.21.1
3. 将 .jar 文件放入 Minecraft 目录的 `mods` 文件夹
4. 使用 NeoForge 1.21.1 配置启动游戏

## 使用方法

在工作台中用 9 个相同的物品即可合成对应的存储方块。放置后可作为建筑材料使用，破坏可获得原始物品。

# Hoarding

[English](./README_EN.md) | 简体中文

## 设计思路

本模组的存储方块设计参考了以下模组的存储系统：

- [Farmer's Delight](https://www.curseforge.com/minecraft/mc-mods/farmers-delight)
- [Quark](https://www.curseforge.com/minecraft/mc-mods/quark)

## 功能

- **102 种原版存储方块**：涵盖各类农作物、花朵、蘑菇和战利品
- **18 种模组整合方块**：Botania 16 色矮花 + Ars Nouveau 2 种
- **9 个物品 = 1 个存储方块**：放置后可作为建筑材料，破坏后返还原物品

## 安装

1. 下载最新版本（[Releases](https://github.com/3453890470/Hoarding/releases)）
2. 安装 Minecraft Forge 1.20.1
3. 将 .jar 文件放入 Minecraft 目录的 `mods` 文件夹
4. 使用 Forge 1.20.1 配置启动游戏

## 模组整合

需先安装对应模组：

- **Botania** - 16 色矮花箱子
- **Ars Nouveau** - 法师之花箱子、魔源浆果箱子
